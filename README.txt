ВЕРСИЯ V3 — МАКСИМАЛЬНО БЛИЗКО К ПРИСЛАННОМУ РЕФЕРЕНСУ

Статическая PWA: без npm, React, Vite и workflow.

Замените в корне GitHub-репозитория: index.html, manifest.webmanifest, sw.js, icon.svg и папку images/.
GitHub Settings -> Pages -> Deploy from a branch -> main -> /(root).

Визуально повторены композиция первого экрана, фото-блок, подписи, шесть карточек, нижняя навигация, тёплая палитра. Внутренние экраны стилизованы в той же системе.

Это фронтенд-демо: ИИ пока имитирует диалог, дневник хранится локально, контакты мессенджеров не подключены. Нужны согласование психологических текстов и защита данных перед запуском.
