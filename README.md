# «Можно быть собой» — PWA Елены Осинцевой

Стартовый MVP на React + TypeScript + Vite.

## Что уже реализовано
- Адаптивный интерфейс для мобильных экранов.
- Главная страница с фотографией Елены.
- Раздел практик с демонстрационными упражнениями.
- Дневник чувств с локальным сохранением в браузере.
- Экран ИИ-помощника с демонстрационными ответами (НЕ подключён к настоящей модели).
- Профиль Елены и заготовки переходов в MAX / Telegram / WhatsApp.
- PWA manifest и Service Worker для базового офлайн-кэширования приложения.

## Запуск
Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Для проверки production-сборки:
```bash
npm run build
npm run preview
```

## Перед публикацией обязательно
1. В `src/App.tsx` заполнить объект `CONTACTS` реальными ссылками Елены:
   - `max`
   - `telegram`
   - `whatsapp`
2. Согласовать с Еленой биографию, профессиональные сведения, направления и описание консультаций.
3. Подключить серверную часть и настоящую ИИ-модель. Нельзя помещать API-ключ в браузерный код.
4. Пересмотреть формулировки психологических практик вместе с Еленой.
5. Добавить полноценную политику конфиденциальности, согласие на обработку данных и защищённую серверную архитектуру до сбора чувствительных данных.
6. Проверить офлайн-режим, восстановление записей, установку на iOS и Android.

## Важные ограничения демоверсии
- Записи дневника хранятся в localStorage браузера и не синхронизируются между устройствами.
- Демо-ответы помощника фиксированные и не являются настоящей ИИ-поддержкой.
- Ссылки на мессенджеры пока не настроены.
- Service Worker кэширует оболочку приложения; требуется отдельное тестирование обновлений и сценариев офлайн-работы.
